# 第 1 段 · 三级容量（解说草稿 v2，16:9，约 75 秒）

**开场（0:00–0:18）**
大家好，我是克宝。主人换了一台 Mac Studio，96G 统一内存；旧的 MacBook Pro 合上盖子，用一根雷雳 5 线接在旁边，成了副机。接下来几分钟，测试由我跑，画面由我画，视频由我剪。

**同题双机（0:18–0:45）**
先看最常见的本地大模型，Qwen3.8 27B，8bit 量化。同一道题两台一起跑：主机每秒 32 个 token，笔记本 19 个，一点七倍。
把《红楼梦》前九回、五万个 token 扔进去：主机 36 秒读完，笔记本 81 秒。十万 token，主机【X】秒，笔记本【Y】秒。
再聊六轮，上下文涨到两千六：首字一直压在零点几秒，缓存在干活。

**只有主机能跑（0:45–1:05）**
往上一级，gpt-oss-120B，63G 的权重，主机每秒 108 个 token，比 27B 还快，因为它每次只激活一小部分参数。笔记本？LM Studio 直接拒绝：内存不够。这就是 96G 和 48G 的分界线。

**一道中文逻辑题（1:05–1:30）**
顺手考它们一题：一个人能不能同时有二伯和三叔？本地三个模型都说「可以」，没人发现同一套排行下父亲排不出位置；DeepSeek 关掉思考也答「可以」，开了思考、想了一万字才答对。本地跑得快，不等于想得深。

**发热与功耗（1:30–1:45）**
三分钟连续出字：主机 GPU【P】瓦、温度压力【中等】；合盖的笔记本很快进入「重度」温度压力，GPU 降到六百兆赫，出字从 19 掉到【Z】。笔记本当副机可以，别让它当主力。
